# Wealth in Whispers

A quiet financial intelligence platform about money, investing, business, risk and behaviour.

## Stack

- Next.js 15
- React 19
- TypeScript
- No database required for V1
- No paid dependencies

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm install
npm run build
npm start
```

## Hostinger deployment

This repository is ready for Hostinger's Node.js Web App deployment flow.

Recommended settings:

- Framework: Next.js
- Node.js: 22
- Install command: npm install
- Build command: npm run build
- Start command: npm start
- Repository branch: main

The project currently needs no environment variables.
